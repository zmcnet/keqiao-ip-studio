# 演示PPT 设计规范（产品演示风 · 深色）

> 用途：《作品演示视频》的**内容载体**——视频"跟着 PPT 讲"，逐页对应配音段落。
> 与答辩PPT的区分：答辩版=学术蓝白（纸面阅读）；演示版=**深色科技演示**（视频播放，视觉冲击）。

## 1. 画布与母版

画布 1280×720。深色底 `#0B1220`，内容区左右留白 64px。

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 顶部 | y 0–92 | 左侧步骤编号胶囊 + 标题；右侧产品名 |
| B 内容 | y 92–656 | 截图 / 图示 / 数据 |
| C 底部 | y 656–720 | 进度条 + 页码 |

## 2. 配色（深色演示）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 底 | `#0B1220` | 页面背景 |
| 卡片 | `#121C2E` / `#18243A` | 面板、代码块 |
| 描边 | `#24344F` | 卡边、分隔 |

## 3. 字体

标题「微软雅黑」Bold；正文「微软雅黑」。标题 34px / 卡标题 22px / 正文 16px / 注 13px。
