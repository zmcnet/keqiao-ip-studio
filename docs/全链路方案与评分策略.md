# 柯桥·水乡IP造物台 —— 全链路方案与评分得分策略

## 一、交付物定义

一个 **Web 端多模态「创编一体」全链路创作工作台**，围绕"柯桥原创旅游IP形象"这一主题，
打通 **意图理解 → 结构化策划 → 角色资产锁定 → 分镜生成 → 时间轴预览 → 成片导出**，
覆盖 **文本 / 图片 / 音频 / 视频** 四类模态。

**核心逻辑（对标 SenseTime Seko / 即梦）**：
策划阶段由 LLM 产出**结构化项目模型**（世界观 + 角色 + 分镜脚本），作为**单一事实源**驱动下游；
先锁定「角色种子图」，后续每个分镜生成以其为 `reference` 参考图，保证**同一角色跨场景形象一致**。

工作台五个功能页签：
1. **智能策划**：输入创意 → LLM 输出结构化项目（世界观 + 3~6 角色 + 6 分镜脚本）
2. **角色资产**：为每位角色生成标准立绘（种子图），锁定一致性锚点
3. **分镜生成**：按分镜脚本逐镜生成画面，自动绑定角色参考图
4. **时间轴预览**：镜头排列成时间轴 + **对话式编辑**（自然语言改分镜）+ 单镜配音
5. **成片导出**：说明文档 / 分镜脚本 / 全量项目 / 角色图
另含 **合规台账**（资源授权登记）与 **AIGC 占比核算**（红线 ≥60%）。

## 三、评分得分策略（每一分怎么拿到手）

### 1. 作品创意 —— 15分｜目标 15-10
- **动作**：原创"三缸奇缘·笛里柯桥"世界观 + 六位绑定真实非遗的IP角色 + 原创落地玩法「三缸集章·水乡寻韵」。
- **满分要点**：打破常规（不套通用萌宠模板）、高辨识度、体现绍兴本地特色。
- **规避**：绝不使用既有IP元素，避免落入"套模板=5-0"。

### 2. 主题表达与场景完整性 —— 25分｜目标 25-15
- **动作**：场景延展图**完整覆盖**柯桥标志性自然景观（鉴湖/柯岩）、人文点位（安昌/柯桥古镇/古纤道）、特色文旅业态（轻纺城/文创/夜游）。
- **满分要点**：非遗融入自然；六位角色各自对应真实地标，形成"完整创作链路"。
- **规避**：只出角色不覆盖地标 → 直接掉档。

### 3. AIGC生成质量 —— 20分｜目标 20-15
- **动作**：工作台自动记录每个环节的**工具选型 + 核心参数 + 提示词**，实时核算 **AIGC占比**（≥60%红线）。
- **满分要点**：多模态素材画质清晰、音视频流畅无失真、文化匹配度极高、无元素错用错位。
- **规避**：占比<60% 或 画面崩坏 → 5-0。

### 4. 内容安全与合规 —— 20分｜目标 20-15
- **动作**：工作台内置**合规台账**，逐一登记第三方素材/预训练模型/背景音乐/艺术字体的来源与授权。
- **满分要点**：全流程资源可追溯、无侵权风险、导向积极正向。
- **规避**：大量无授权商用资源 → 5-0。

### 5. 传播价值与应用推广前景 —— 10分｜目标 10-8
- **动作**：明确落地场景（集章手账、AR导览、衍生品、景区大屏、短视频）。
- **满分要点**：可直接落地、适配多元传播场景、可复制性强。

### 6. 作品演示展示效果 —— 10分｜目标 10-8
- **动作**：录制工作台全流程操作演示视频（1080p / H.264），PPT≤15页，10分钟内讲清核心价值。
- **满分要点**：流畅呈现"全流程操作逻辑 + 最终成果"。

## 六、工作台技术架构（Web）

```
keqiao-ip-studio/
├─ index.html            前端单页应用（创编一体流水线）
├─ server.py             本地代理服务（静态托管 + SenseAudio API 代理 + 自动降级）
├─ config.json           API 配置（密钥仅服务端，不下发前端）
├─ assets/
│  ├─ css/app.css        样式
│  ├─ generated/         真实模型成果（6角色立绘 + 6分镜图）
│  └─ js/
│     ├─ ipdata.js       项目数据内核（world / characters / shots / 色卡 / 证据链 / 台账）
│     ├─ render.js       参数化SVG渲染器（模拟层）
│     └─ app.js          流水线逻辑（五环 + 真实模型 + 对话式编辑 + 导出）
└─ docs/                 设计文档
```

- 前端：原生 HTML/CSS/JS；真实模型经本地代理 `/api/*` 调用，密钥不下发；
- 上游不可用时**自动降级模拟层**，保证任意环境可演示；
- 角色一致性：`/api/image` 的 `reference` 参数（角色种子图 Data URI）；
- 结构化策划：`/api/plan` 使用 `response_format=json_object`。
