柯桥·水乡IP造物台 —— 生产环境部署指南与运维记录
**适用范围**：Ubuntu 24.04 LTS · Nginx + systemd + Python 应用

## 二、架构

```
Internet ──:443(HTTPS)──> Nginx ──┬── 静态资源  /opt/keqiao-ip-studio
                        (SSL / 安全头 / 限流)
                                  └── /api/*  反代 ──> 127.0.0.1:8899 (Python server.py)
                                                          └──> SenseAudio API（密钥仅存服务端）
```

- **Nginx**：TLS 终止、静态托管、安全响应头、限流、源码防护
- **keqiao-ip-studio.service**：Python 应用，仅监听 `127.0.0.1:8899`（外网不可直连）
- **上游 API**：SenseAudio 全模态，密钥经环境变量注入，绝不下发前端

## 三、目录与文件

| 路径 | 用途 | 权限 |
|------|------|------|
| `/opt/keqiao-ip-studio/` | 应用根目录（index.html + assets/ + server.py + config.json） | www-data:www-data |
| `/opt/keqiao-ip-studio/config.json` | 非敏感配置（不含密钥） | 640 www-data |
| `/etc/keqiao-ip-studio/secret.env` | **API 密钥**（`SENSEAUDIO_API_KEY`） | **600 root** |
| `/etc/systemd/system/keqiao-ip-studio.service` | 服务单元 | 644 root |
| `/etc/nginx/sites-available/keqiao-ip-studio.conf` | Nginx 站点配置 | 644 root |
| `/etc/nginx/conf.d/keqiao-limits.conf` | 限流定义 | 644 root |
| `/etc/fail2ban/jail.local` | 防爆破策略 | 644 root |
| `/etc/ssh/sshd_config.d/99-hardening.conf` | SSH 加固 | 600 root |
| `/etc/letsencrypt/live/<your-domain>/` | SSL 证书 | root |

## 四、安全防护清单

| 项 | 配置 |
|----|------|
| **SSL** | Let's Encrypt，配合 `certbot.timer` 自动续期（务必先做 `--dry-run` 验证） |
| **HTTPS 强制** | 80 端口除 ACME 校验外一律 301 跳转 |
| **HSTS** | `max-age=31536000; includeSubDomains` |
| **安全响应头** | CSP / X-Content-Type-Options / X-Frame-Options / Referrer-Policy / Permissions-Policy / COOP |
| **防火墙** | UFW：默认拒绝入站，仅放行 22 / 80 / 443 |
| **端口收敛** | 应用 8899 仅监听 127.0.0.1，外网不可达 |
| **SSH 加固** | 仅密钥认证、禁 root 直连、MaxAuthTries 4、空闲 10 分钟断开 |
| **fail2ban** | sshd（多次失败封禁）+ nginx-http-auth + nginx-bad-request |
| **限流** | /api/ 每 IP 60 请求/分钟（burst 20），并发连接 20 |
| **Origin 白名单** | server.py 仅放行你配置的域名 + 回环，跨站盗用返回 403 |
| **源码防护** | `/server.py`、`/config.json`、`/.git` 等一律 404 |
| **密钥隔离** | 密钥仅存于 600 权限的 root 文件，web 目录零明文 |
| **systemd 加固** | NoNewPrivileges / ProtectSystem=strict / PrivateTmp / MemoryDenyWriteExecute 等 |
| **服务韧性** | 全部服务 enabled（开机自启），Restart=always |

## 五、运维命令

```bash
# 服务管理
sudo systemctl status keqiao-ip-studio nginx fail2ban
sudo systemctl restart keqiao-ip-studio      # 改代码后重启应用
sudo systemctl reload  nginx                 # 改配置后热重载

# 日志
sudo journalctl -u keqiao-ip-studio -f       # 应用日志
sudo journalctl -u nginx -n 50               # Nginx 日志
sudo tail -f /var/log/nginx/access.log

# 证书
sudo certbot certificates                    # 查看证书
sudo certbot renew --dry-run                 # 测试续期

# 防护
sudo fail2ban-client status sshd             # 查看封禁情况
sudo ufw status verbose                      # 防火墙状态

# 配置校验（改完务必先测）
sudo nginx -t
sudo sshd -t
```

## 六、更新部署（改代码后）

```bash
# 本地
scp -i ~/.ssh/<your-key>.pem -r index.html assets server.py <user>@<server-ip>:/tmp/kq/

# 服务器
sudo cp -r /tmp/kq/* /opt/keqiao-ip-studio/
sudo chown -R www-data:www-data /opt/keqiao-ip-studio
sudo systemctl restart keqiao-ip-studio
```

> ⚠️ 若需更换 API Key：编辑 `/etc/keqiao-ip-studio/secret.env` 后
> `sudo systemctl restart keqiao-ip-studio`（**切勿**把密钥写入 web 目录）。

## 七、踩坑记录（供后续参考）

1. **sshd 配置覆盖顺序**：`sshd_config.d/` 按**文件名字典序**加载且 sshd **取首个值生效**。所以 `50-cloud-init.conf`（内含 `PasswordAuthentication yes`）会压制 `99-hardening.conf`——必须直接改写前者，并用 `/etc/cloud/cloud.cfg.d/99-kq-ssh.cfg` 的 `ssh_pwauth: false` 防止 cloud-init 回写。
2. **nginx 1.24 不支持 `http2 on;`**（1.25+ 语法），须用 `listen 443 ssl http2;`。
3. **`options-ssl-nginx.conf` 已含** `ssl_session_timeout` / `ssl_stapling` 等，重复声明会导致 `nginx -t` 报 duplicate。
4. **location 级 `add_header` 会覆盖继承的服务器级安全头**，静态资源用 `expires` 而非 `add_header Cache-Control`。
5. **certbot --nginx 会重写 80 端口块为 `return 404`**，会切断 ACME 续期通道——重写站点配置时必须保留 `/.well-known/acme-challenge/` 的 `location`。
