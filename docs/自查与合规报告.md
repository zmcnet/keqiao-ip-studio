# 自查与合规报告（Self-Audit & Compliance）

> 对象：「柯桥·水乡IP造物台」——数字创意与AIGC应用赛道 · 主题一 · 选项B
> 方法：对全工程（前端 / 代理 / 数据 / 文档）逐文件审读，从**安全性、合规性、逻辑正确性、工程质量、评分对齐**五个维度自查。
> 本报告如实记录**已发现的问题与处置**，供评审参考，也作为团队的质量台账。

---

## 一、安全性（Security）

| # | 问题 | 风险等级 | 处置 |
|---|------|---------|------|
| S1 | 本地代理原设 `Access-Control-Allow-Origin: *`，持有 API Key 的本地服务可被**任意网页跨站调用**，盗刷额度 | 🔴 高 | **已修复**：改为 Origin 白名单（仅 127.0.0.1/localhost/::1），非本地来源返回 **403**（已实测拦截 `evil-site.com`） |
| S2 | API Key 明文存于 `config.json` 且随工程走 | 🟠 中 | **已缓解**：新增 `.gitignore` 忽略 `config.json`；提供 `config.example.json` 模板；支持环境变量 `SENSEAUDIO_API_KEY` 覆盖；Key **仅服务端持有，绝不下发前端** |
| S3 | 静态文件路径校验用 `startswith(ROOT)`，存在**前缀绕过**（`C:\app` vs `C:\app2`） | 🟡 低 | **已修复**：改用 `os.path.commonpath([ROOT, fp]) == ROOT` |
| S4 | `/api/health` 回显 `key_prefix`，属信息泄露 | 🟡 低 | **已修复**：移除前缀，仅返回 `key_loaded` 布尔值 |
| S5 | POST 请求体无大小限制，可被超大 body 撑爆内存 | 🟡 低 | **已修复**：限制 24MB，超限返回 413 |
| S6 | 前端把 LLM 返回文本直接插入 `innerHTML`，存在 **XSS** 面 | 🟠 中 | **已修复**：`esc()` 转义补齐 `"` `'`，所有动态文本统一转义 |

> 说明：服务仅绑定 `127.0.0.1`（不对外网开放）；`.gitignore` 已排除密钥与缓存。

## 二、合规性（Compliance）

| # | 问题 | 风险等级 | 处置 |
|---|------|---------|------|
| C1 | 合规台账原先写"思源黑体/霞鹜文楷(SIL OFL)"，但工程**根本未使用这些字体** —— 属**授权说明与实际不符** | 🔴 高 | **已修复**：改为如实标注「系统内置字体（微软雅黑/苹方），未嵌入第三方字体」；台账扩充为 8 条，覆盖平台/模型/字体/图标/资料/生成内容 |
| C2 | 作品图片为 1024×1536，**远达不到赛题 A3(297×420mm)/300dpi** 规格 | 🔴 高 | **已修复**：新增 `/api/export_sheet`，用 PIL 将成图等比放大并居中贴合 A3 版面，写入 300dpi 元数据（实测输出 **3508×4961 @300dpi**）；导出按钮「导出作品图片（A3·300dpi）」 |
| C3 | 导出文件名未遵循 `[队伍编号]` 命名规则 | 🟠 中 | **已修复**：新增「队伍编号」输入，所有导出文件按 `[编号]说明文档` / `[编号]作品视频_xxx_A3.jpg` 等命名 |
| C4 | AIGC 占比的"80%"由写死常量算出，**缺可辩护依据** | 🟠 中 | **已缓解**：界面明示口径——"各创作环节中 AIGC 承担比例之均值（余量为人工选题/参数/审美筛选）"，并逐环节列出占比，可复现 |
| C5 | 作品不得出现姓名/校名等无关标识；需原创、无 IP 纠纷 | — | **已核**：工程与生成物中无任何姓名/校名标记；IP 形象与分镜全部原创，未使用既有 IP 元素 |
| C6 | 政治方向/舆论导向、内容安全 | — | **已核**：主题为柯桥文旅/非遗，导向积极正向；生成内容经平台内容安全过滤 |
| C7 | 第三方资源来源与授权需逐一标注 | — | **已核**：见工作台「合规台账」及说明文档第七节 |

## 三、逻辑正确性（Functional）

| # | 问题 | 风险等级 | 处置 |
|---|------|---------|------|
| F1 | 重新策划后**旧分镜图未清空**，新项目会张冠李戴 | 🟠 中 | **已修复**：`plan()` 成功后清空 `shotImages` |
| F2 | 角色参考图用 `fetch()` 抓远程图，**可能被 CORS 拦掉**，导致一致性静默失效 | 🔴 高 | **已修复**：新增 `/api/fetch_image`，由服务端取图转 Data URI，规避 CORS |
| F3 | 分镜生成时若参考图缺失，一致性"名存实亡" | 🟠 中 | **已缓解**：日志显式提示"参考图已加载/缺失"，便于排查 |
