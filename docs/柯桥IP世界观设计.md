# 柯桥·水乡IP家族 —— 世界观与角色设定（设计稿 v1）

> 赛道：数字创意与AIGC应用 · 主题一（绍兴柯桥区地方文旅宣传）· 选项B（原创柯桥专属旅游IP形象）
> 世界观母题：**三缸奇缘 · 笛里柯桥**（柯桥古称"笛里"，源出柯亭笛）

---

## 一、世界观设定

**地名**：笛里·柯桥 —— 一座"城在景中、景浮水中、水融诗中"的江南水乡秘境。

**起源**：东晋柯亭，蔡邕取柯亭竹制笛，笛声引动鉴湖千年水气。水气凝作六位"水乡小匠"，居于柯亭竹影之间，守着柯桥的山水、古镇与人情。

**核心设定 · 三缸灵脉**：
柯桥的元气，藏在三口古缸里——
- **酒缸**（醇）——鉴湖水酿的绍兴黄酒，是这片水土的暖；
- **酱缸**（鲜）——仁昌酱园的母子酱油，是这片水土的味；
- **染缸**（彩）——柯桥轻纺的纺织印染，是这片水土的色。

"三缸"由柯桥先民的匠心所化，维系着水乡"有滋有味、有色有香"的生活底色。六位小匠的使命，是守护这条灵脉，把柯桥之美带向四方（呼应现实中的"游百城千湖"）。

**精神内核**：越地匠心的"守"与"传"——一劈一磨的耐心、雨淋不透的坚守、千年不息的传承。

## 三、原创落地玩法（对应"作品创意"15分）

**「三缸集章 · 水乡寻韵」**：
1. 六位小匠分别驻守柯桥六个真实点位（柯岩/鉴湖、安昌古镇、柯桥古镇、鲁镇、王星记扇厂、古纤道）；
2. 游客凭"集章手账"（呼应安昌古镇已有的"集章本"玩法）逐一打卡；
3. 结合柯桥既有 AR 项目（"智游柯桥·镜揽世界"）做"小匠 AR 导览"；
4. 衍生品链路：折扇、黄酒周边、蓝印花布、文创伴手礼——满足赛题"衍生品开发 + 线下文旅场景落地"。
