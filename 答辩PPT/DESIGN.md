# DESIGN.md · 柯桥·水乡IP造物台 答辩PPT 设计稿

> 命中风格分支：**学术风**（design-principle.academic.md）——用户场景为高校竞赛答辩，明确属于学术汇报。
> 按分支规则：**结构层完整执行**；**常量值层按项目需求微调**（水乡文旅主题需一线"水系蓝"与"朱砂红"点缀，弃用与本主题无关的金色；L1 配图改用作品真实产出，符合"证据化配图"要求）。
> 画布：1280×720。

---

## 1. 母版骨架（结构层，锁定执行）

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 页眉 / 标题块 | y 0–112 | 左侧细竖条 + 主标题 32px Bold 深蓝；右上角小号章节标记 |
| B 内容区 | y 112–660 | 可用高 548px、宽 1200px（左右 padding 40） |
| C 页脚条 | y 660–700 | 左侧项目名 14px 灰 + 右侧页码 `NN / 15` 14px 深蓝 |

- 页面 padding：上下 20、左右 40（画布内安全区）。
- 内容页必须铺满 B 区，元素累计高 ≥96%（学术风"撑满优先"）。
- 封面 / 目录 / 章节扉页 / 结束页采用自定义版式（省略 C 区页码或改用章节大字）。
- 全篇顶条模式统一：内容页一律 A3（浅顶条 + 深蓝分隔线）。

## 2. 色彩系统（常量值层微调）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 主色 · 鉴湖深蓝 | `#1E4FA8` | 顶条、编号、标题、强调 |
| 主色 · 水乡靛蓝 | `#0E3F8C` | 深底块、章节扉页、重点强调 |
| 辅色 · 浅湖蓝 | `#E8EFF8` | 卡片底、表头浅底、分隔 |
| 强调 · 朱砂 | `#C0392B` | 仅关键数据 / 风险提示，单页 ≤3% |
| 文本 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助 |
| 线框 | `#D6DCE5` / `#E5E7EB` | 描边、表格线 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 主背景 |

**色彩面积分配**（学术风合规）：

| 色彩角色 | 面积占比 | 说明 |
| :-- | :-- | :-- |
| 主色（蓝族） | 35–55% | 顶条、背景块、标题栏 |
| 辅色（浅湖蓝/白） | 30–55% | 卡片底、留白区 |
| 强调色（朱砂） | ≤5%（Hero 页可至 8%） | 巨型数字、关键标注 |
| 中性色 | 剩余 | 文本、页脚、边框 |

- 配色比：蓝族 35–55%，白底 30–55%，浅蓝 0–35%，朱砂 ≤3–8%，**不使用金色**（本主题无政务属性）。
- 禁紫粉玫红、橙绿大色块、彩虹渐变、纯黑大底。

### 渐变与半透明
- 章节扉页底图叠加 `rgba(14,63,140,0.72)` 蒙版，确保白字可读。
- 卡片使用 `boxShadow: '0 4px 20px rgba(30,79,168,0.08)'` 创造浮起感。
- 元素重叠时底层 `opacity: 0.15–0.3`。

## 3. 字体系统

字体家族 **≤2 套**：标题用「**微软雅黑**」（Bold），正文用「**微软雅黑**」（Regular）——学术风要求克制，中文系统字体，规避字体版权风险（与本作品合规台账一致）。

| 层级 | px | 字重 | 行高 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| 封面中文主标 | 64 | bold | 1.2 | 仅封面 |
| 章节大数字 | 200 | bold | 1.0 | 章节扉页 |
| 章节大字 | 56 | bold | 1.1 | 章节过渡 |
| **巨型数据/锚点** | **96** | **bold** | **1.0** | AIGC占比 80% 等核心数字 |
| 页面主标题（A 区） | 34 | bold | 1.3 | 每页固定 |
| 卡片小标题 | 24 | bold | 1.4 | 卡片头 |
| 正文 | 19 | regular | 1.5 | 段落 |
| 表格 | 17 | regular | 1.5 | 表头、表体 |
| 脚注 / 页码 | 14 | regular | 1.4 | 页脚条右下 |

> 注：学术风正文下限 22px 适用于纯段落长文页；本项目为答辩信息页，卡片文字密集，采用 19px 正文 + 24px 卡标题，保证「撑满 + 不溢出」二者平衡（已在页面映射表逐页核验字数）。

## 4. 信息密度门禁（逐页达标）

| 页面类型 | 本设计标准 |
| :-- | :-- |
| 封面 | 主标 + 副标 + 落款 + 主视觉（B 区 ≥35%） |
| 目录 | 3 条目 + 引导句，合计 ≥80 字 |
| 内容页 · 卡片组 | 每卡 ≥100 字（3 卡时合计 ≥300） |
| 内容页 · 单主题 | ≥180 字 + 主视觉 |
| 数据页 | 主数字 + 拆分依据 ≥100 字 |
| 章节扉页 | 大数字 + 标题 + 2 条要点，≥60 字 |

- 常规内容页留白 ≤35%；Hero 页允许 40–50%（围绕核心元素）。
- 卡片填充率 ≥85%；高 ≥380px 的卡正文 ≥130 字。

**版式约束核验**：
- 非对称版式：01/05/06/08/09/10/12/13/14/15 = 10 页，占 67%（≥40% ✅）
- `N卡片横排`：0 页（未使用，规避"AI 味"）
- 相邻页版式：无重复 ✅
- 连续 ≥2 页对称版式：仅扉页与目录（自定义版式，不占额度）

**Hero 页核验**：01 / 06 / 09 / 13 / 15 = 5 页？→ 复核：01 封面、06 IP家族、09 角色一致性、15 结束页 = 4 页，占 27%（13 页为 supporting·peak，非 hero）。
- Hero 不邻：01 → 06（间隔 4 页）→ 09（间隔 2 页）→ 15（间隔 5 页）✅
