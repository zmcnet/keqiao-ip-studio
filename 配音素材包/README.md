# 配音素材包 —— 使用说明

> 柯桥 · 水乡IP造物台 ｜ 两个视频的**全部配音素材**
> 生成方式：SenseAudio TTS（`gen_vo2.py`）｜ 拼接：`make_vo_tracks.py`

---

## 一、包里有什么

```
配音素材包/
├─ 配音剧本.md                    ⭐ 完整剧本（精确时间轴 + 分角色音色 + 真动态素材清单）
├─ 配音台词对照表.csv             ⭐ 逐段对照表（影片/时间码/时长/画面/音色/文件/文本）
├─ 音频_逐段/                     ⭐ 18 段独立配音（可直接单独替换任一段）
│   ├─ c0_title.mp3 ~ c7_outro.mp3    内容成片 8 段
│   └─ d0_hook.mp3 ~ d9_end.mp3       演示视频 10 段
└─ 完整配音轨/                    ⭐ 两片整轨（按时间轴拼好的完整旁白）
    ├─ 作品视频_完整配音.mp3         103.28 秒
    └─ 作品演示视频_完整配音.mp3     157.50 秒
```

---

## 二、三种用法

### 用法 A：只想换掉某一句 → 用「音频_逐段/」

按 `配音台词对照表.csv` 找到对应文件，替换后重跑合成：

```bash
python build_v2.py all      # 重新合成两个视频
```

> 合成脚本按 `视频_work/vo2/durations.json` 中的**实测时长**自动对轴，
> 所以替换音频后无需手动改代码——但若新配音与旧配音时长差异较大，
> 建议同步更新 `durations.json`（或直接重跑 `gen_vo2.py` 重新生成全部）。

### 用法 B：只想换掉整条旁白 → 用「完整配音轨/」

把整轨音频直接铺到视频时间轴上即可（配音总长与成片时间轴一致）。

### 用法 C：想重新配音（换音色 / 改文案）→ 改剧本后重跑

1. 编辑 `配音剧本.md` 中的文本；
2. 修改 `gen_vo2.py` 里的 `LINES` 列表（key / 音色 / 文本）；
3. 依次执行：

```bash
python gen_vo2.py           # 重新生成 18 段配音 + 实测时长
python make_vo_tracks.py    # 重新拼完整配音轨
python build_v2.py all      # 重新合成两个视频
```
